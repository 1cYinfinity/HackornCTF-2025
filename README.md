</br>This repository contains detailed writeups for challenges from HackornCTF-2025 across multiple categories including CRYPTO, FORENSIC, MISC, OSINT, PWN, Threat Intel L1 & L2, and WEB.

## Repository Structure

* **CRYPTO/** — Challenges related to cryptography and cipher solving.
* **FORENSIC/** — Challenges involving file analysis, memory forensics, and artifact recovery.
* **MISC/** — Miscellaneous challenges that don't fit into other categories.
* **OSINT/** — Open-source intelligence challenges, such as domain or email investigations.
* **PWN/** — The challenges focus on Windows & Linux domain engagements, AD enumeration, and AD privilege escalation techniques.
* **Threat Intel L1/** — Level 1 Threat Intelligence challenges focusing on basic phishing and malware analysis.
* **Threat Intel L2/** — Level 2 Threat Intelligence challenges with deeper analysis of campaigns, network traces, and indicators of compromise.
* **WEB/** — Web exploitation challenges including XSS, SQLi, and authentication bypasses.

## Usage

Each folder contains individual writeup files (Markdown or text) describing the challenge, methodology, tools used, and the solution including the flag. These are intended for educational purposes and learning cybersecurity techniques.
